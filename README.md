# 不问凡尘 · 存档修改器

《不问凡尘》（World Apart）的**离线存档修改器**。直接读写本地存档文件，不注入游戏进程；每次写入前自动备份，改坏了可以一键撤销或还原。

> 本工具与《不问凡尘》官方无关，请支持正版游戏。

## 适配版本

| 项目 | 版本 |
|---|---|
| 游戏 | 《不问凡尘》Steam 版（AppID 4209920） |
| 适配的游戏版本 | **Steam Build 26646193**（2026-11-14 更新） |
| 存档格式 | 2.0.0（内容版本 4） |

游戏更新后，修改器标题栏会提示"游戏已更新"。新版本游戏新增的物品、丹方等不会出现在列表里，个别功能也可能不准，请先备份再改，并留意本项目的更新。

## 下载

到本页右侧的 **Releases（发布）** 下载最新的 `exe`，双击就能用，不用安装。需要 Windows 自带的 .NET Framework 4.x（Windows 10 / 11 都有）。

**只从这个仓库的 Releases 下载才是原版。** 本工具免费，如果你是花钱买到的，说明被人倒卖了。

## 功能

| 分类 | 功能 |
|---|---|
| NPC | 修改天赋槽（区分固定 / 随机天赋，固定天赋不可改）、好感（满 500）、境界、寿元 |
| 同道 / 道侣 / 洞府 | 结为 / 解除同道（按境界检查人数上限）、结缘 / 解除结缘、设主道侣、洞府住客、批量满好感 / 解锁天赋槽 |
| 修炼 | 道途点 / 灵根点重置、善恶值、魅力值、魔气值、五项探索属性、属性加成、精力、直接学会功法心法 |
| 物品 | 添加物品（含功法秘籍、丹药、未炼制法宝、璞石）、改数量、删除；法宝主属性 / 词条 / 品阶 / 词条槽 |
| 炼丹 / 炼器 | 丹方图鉴（查漏补缺、来源提示、药效词条、补录）、炼丹等级、丹炉、炼丹天赋、丹药服用次数重置；炼器等级与炼器天赋 |
| 其他 | 灵石 / 贡献 / 城镇和宗门声望、地图迷雾、游戏难度、一键撤销、存档对比 |

修改器里自带"使用教程"页，第一次用请先看一遍。

## 使用方法（三步）

1. **关掉游戏**（最稳妥）。
2. 在修改器上方选一个存档，推荐选手动存档（manual_xx）。
3. 左侧选功能页修改，大部分按钮点一下就会写入（并自动备份）。然后打开游戏读取这个存档。

游戏开着也能改：写入后在游戏里**直接读取这个存档**即可生效，不要先存档。

## 备份在哪里

`文档\WorldApartSaveEditor_Backups\`。第一次修改前的原档永久保留，另外保留最近 20 份。修改器上方的"撤销上一次修改"和"还原备份…"都能用。

## 自己编译

只需要 Windows 自带的 .NET Framework 4.x，不用装 Visual Studio：

```
build.bat
```

会生成 `WorldApartSaveEditor.exe`。源代码是单个文件 `Program.cs`（C# / WinForms），游戏数据表是同目录下的 `*.tsv`。
